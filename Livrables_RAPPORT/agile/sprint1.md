Le premier Sprint est consacré à la préparation d'une base de données fiable pour les étapes de Machine Learning.
Les travaux portent principalement sur :
-	l'ingestion du dataset ; 
-	le stockage des données ; 
-	la transformation ; 
-	les contrôles de qualité ; 
-	la préparation du pipeline ; 
-	l'orchestration avec Dagster. 

 L'objectif est d'obtenir des données propres, cohérentes et exploitables par la suite du pipeline.
