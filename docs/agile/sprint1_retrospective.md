Points positifs
-	Répartition claire des responsabilités ; 
-	utilisation de Jira pour suivre les travaux ; 
-	utilisation de GitHub pour collaborer ; 
-	séparation des étapes DataOps et Machine Learning. 
Difficultés rencontrées
-	Coordination entre les différentes étapes du pipeline ; 
-	synchronisation du travail entre plusieurs branches ; 
-	dépendance entre la préparation des données et le développement ML. 
Actions d'amélioration
-	Décomposer les grandes User Stories en sous-tâches ; 
-	effectuer des Pull Requests régulières ; 
-	documenter les interfaces entre les différentes parties du pipeline.
