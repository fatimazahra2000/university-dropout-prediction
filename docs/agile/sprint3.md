Le troisième Sprint est consacré à l'industrialisation de la solution Machine Learning.
Les principaux travaux sont :
-	développement de l'API FastAPI ; 
-	intégration du modèle ; 
-	création des endpoints ; 
-	conteneurisation Docker ; 
-	orchestration des services ; 
-	mise en place de la CI/CD ; 
-	déploiement manuel sur Komodo. 
L'objectif final est de rendre le système accessible et reproductible dans un environnement proche d'un contexte réel de production.
