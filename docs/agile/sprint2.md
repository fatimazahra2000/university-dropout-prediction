Le deuxième Sprint constitue le cœur du projet de Machine Learning.
L'objectif est de construire un modèle permettant de classifier les risques de décrochage universitaire à partir des caractéristiques comportementales et académiques des étudiants.
Les travaux prévus sont :
1.	Préparer les données ; 
2.	réaliser l'analyse exploratoire ; 
3.	effectuer le Feature Engineering ; 
4.	séparer les données en Train, Validation et Test ; 
5.	entraîner plusieurs modèles ; 
6.	comparer leurs performances ; 
7.	sélectionner le meilleur modèle ; 
8.	réaliser l'évaluation finale ; 
9.	générer la matrice de confusion ; 
10.	versionner les artefacts du modèle ; 
11.	intégrer le suivi des expériences avec MLflow.
